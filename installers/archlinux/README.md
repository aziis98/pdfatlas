# Arch Linux

PDF Atlas is packaged on the AUR as [`pdfatlas-git`](https://aur.archlinux.org/packages/pdfatlas-git).

Install with your AUR helper of choice:

```bash
paru -S pdfatlas-git
# or
yay -S pdfatlas-git
```

Pass `--devel` to rebuild against the latest commit from the git repository:

```bash
paru -S --devel pdfatlas-git
# or
yay -S --devel pdfatlas-git
```

The PKGBUILD and build sources live in the AUR repository and are maintained there.
